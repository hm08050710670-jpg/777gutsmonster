GUTS MONSTERS — 採用BGM 4曲セット
=================================

【収録曲と出典】
01 GUTS TOWN / 112 BPM / 約51.43秒 / v01
   ガッツタウン。明るい冒険の始まり。
02 OKUMURA LAB / 96 BPM / 50.00秒 / v01
   オクムラ研究所。知的で、少し不思議な雰囲気。
03 A: ADVENTURE / 156 BPM / 約30.77秒 / 野生戦v02・A
   野生モンスター戦。王道RPG感とワクワク。
04 RIVAL BATTLE / 168 BPM / 約45.71秒 / v01
   ノブオとのライバル戦。

【野生戦Aの版について】
今回指定された「A：ADVENTURE」という曲名に一致するv02 A（156 BPM）を収録。
直近に渡したv05 A「草むらの挑戦」（160 BPM）とは別の曲です。
このセットではテンポ変更をせず、v02 Aの元WAVをそのまま収録しています。

【フォルダー構成】
wav/     元のWAVデータ。22,050 Hz / 16bit PCM / ステレオ。
mp3/     個別試聴用MP3。元WAVから192 kbpsで書き出し。
manifest.json    曲名・用途・BPM・出典・長さ・ハッシュ等。
qa/verification.json    今回のファイル検証記録。

【変更範囲】
元の配布ZIPから採用曲だけを取り出し、ファイル名を整理した再梱包です。
WAVの音声内容は元ファイルとバイト単位で一致します。
再作曲・音程変更・テンポ変更・音量加工・フェード追加はしていません。
未採用曲は入れていません。ゲーム本体やGitHubのデータも変更していません。

【再生・実装】
再生速度は1.0のままで使用してください。
WAVは元のループ再生想定データを保持しています。
今回ループ境界の調整や、実ゲームでの連続ループ再生・効果音との音量調整はしていません。
MP3は聴き比べや個別試聴用です。ゲームのループ設定は実装時に確認してください。

【今回確認した内容】
元ZIPのCRC、4曲のWAV原本との完全一致、WAV全フレーム読み込み、
WAV/MP3の全体デコード、長さ、サンプルレート、チャンネル数、音量ピーク。
iPhone実機での再生、ゲーム組み込み後の再生、聴感によるループ確認は未実施。
