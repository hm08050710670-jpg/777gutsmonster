# ガッツボール 基本デザイン（基準仕様）

ゴルフボールをモチーフにした、モンスター捕獲用のボール。

- 全体は白〜薄いグレーを基調とした球体。表面にゴルフボールらしい細かなディンプル
- 球体の中央を一周する、黒〜濃いグレーの横ライン1本（ここが上下の開閉部）
- 中央ボタンや「G」マークは付けない。上下とも同じ白いゴルフボール素材
- 輪郭は黒〜濃いグレー。白・薄いグレー・グレー・黒中心の少ない色数のドット絵（GBA風）
- ディンプルは小さい画面でも「ゴルフボール」と分かる大きさ
- 演出：命中 → 中央ラインから上下に「パカッ」と開く → 青〜水色の光で吸い込む → 閉じて数回揺れる（判定）
  → 成功：閉じたまま光・星 ／ 失敗：再び開いてモンスターが戻る

一言で：「中央に黒い開閉ラインだけが入った、シンプルな白いゴルフボール型の捕獲アイテム」
