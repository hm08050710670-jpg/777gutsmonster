# GB RPG Skeleton

初代ゲームボーイ風（160×144・4階調・タイル移動・ターン制戦闘）の
スマホブラウザ向けRPGの土台です。**依存ゼロ・ビルド不要**。`index.html` を開くだけで動きます。

※ 画像・モンスター・マップ・文章はすべてオリジナルの仮素材です。既存作品の素材は含みません。

## 動かし方

- ローカル: `index.html` をブラウザで開く（フォント読込のため、`python3 -m http.server` などのローカルサーバ経由が確実）
- 公開（GitHub Pages）:
  1. このフォルダをGitHubリポジトリにpush
  2. リポジトリの **Settings → Pages → Build and deployment** で
     Source: `Deploy from a branch`、Branch: `main` / `/ (root)` を選んで Save
  3. 数分後 `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける（スマホのホーム画面に追加するとフルスクリーンになります）

## 操作

| 操作 | 仮想パッド | キーボード |
|---|---|---|
| 移動・カーソル | 十字キー | 矢印 / WASD |
| 決定・話す・文字送り（長押しで高速） | A | Z / Space |
| キャンセル | B | X / Esc |
| メニュー | START | Enter |

## 実装済み

- タイトル（はじめから／つづきから）
- フィールド：タイル移動、カメラ追従、看板・NPC会話、回復NPC、草むらエンカウント
- メッセージウィンドウ：文字送り、2行ページ送り、はい／いいえ
- スタートメニュー：なかま／もちもの（きずぐすり）／セーブ（localStorage）
- 戦闘：たたかう／なかま（交代）／どうぐ／にげる、タイプ相性、初代式ダメージ計算、HPバーアニメ、経験値とレベルアップ、全滅時の復帰
- スマホ対応：整数倍スケーリング、縦・横レイアウト、セーフエリア、マルチタッチ（ボタン間スライド対応）

## 未実装（次に決めること）

- マップ切替（建物の中など）— `DATA.MAPS` に追加して `door` イベントから遷移させる想定
- 捕獲・進化・技覚え・トレーナー戦
- BGM／効果音
- 仮素材の差し替え（`js/gfx.js` の文字列ドット絵 → 画像ファイル読込に切替も可）

## ファイル構成

```
index.html          画面とスクリプト読込順
css/style.css       外枠・仮想パッド
js/config.js        解像度・パレット・各種定数（ここをまず調整）
js/input.js         キーボード＋仮想パッド
js/text.js          フォント描画・折り返し・枠
js/gfx.js           ドット絵（文字列 → canvas）
js/data.js          モンスター・技・アイテム・マップ・イベント（内容を変えるならここ）
js/save.js          セーブ／ロード
js/game.js          ループ・シーンスタック・スケーリング
js/scenes/          title / field / dialog / menu / battle
assets/fonts/       美咲ゴシック（8×8日本語ビットマップ・自由利用可、LICENSE同梱）
tools/smoke-test.js スマホ相当のヘッドレスブラウザで一通り操作する検証スクリプト
```

## 設計の要点

- 内部解像度は常に160×144。`Game.fit()` が端末幅に合わせて整数倍に拡大する
- 画面は「シーン」の重ね合わせ（`Game.push / pop`）。ダイアログやメニューは `overlay: true` で下の画面の上に描く
- 戦闘の進行は「ステップの列」（`queue`）。メッセージ→計算→HPアニメ→次、を順番に処理する
- データとロジックを分離。新モンスターや新マップは `js/data.js` の追記だけで増やせる

## 検証

```
npm i playwright && npx playwright install chromium
node tools/smoke-test.js
```
`tools/shots/` にスクリーンショットが出力され、コンソールに各段階の状態と JS エラーが表示されます。
